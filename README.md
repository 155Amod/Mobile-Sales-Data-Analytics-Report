# 📱 Mobile Sales Data Analytics Dashboard

An interactive Power BI dashboard built to analyze mobile sales performance and customer insights.

# 📊 Dashboard Highlights

* 💰 Total Sales & Quantity
* 📦 Transaction Analysis
* 📱 Sales by Mobile Model and Brand
* 💳 Sales by Payment Method
* ⭐ Customer Ratings
* 🌍 Sales by City
* 📅 Monthly and Daily Sales Trends
* 🔍 Interactive filters for Mobile Model, Payment Method, Brand, Customer Name, and Month

# 🛠️ Tools Used

* Power BI
* DAX
* Data Visualization
* Data Cleaning & Transformation

# 🎯 Objective

To provide a clear, interactive view of mobile sales data and help identify **sales trends, customer preferences, top-performing products, and payment patterns.
